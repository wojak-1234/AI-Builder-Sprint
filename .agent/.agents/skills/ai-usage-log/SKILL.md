# Purpose

Maintain a chronological record of AI-assisted development activities.

## Use this skill when

- AI is used for architecture
- AI generates implementation code
- AI assists with debugging
- AI creates documentation
- AI generates tests
- AI proposes design decisions
- AI performs code review

## Workflow

1. Open `aiUsageLog.md`.
2. Append a new entry.
3. Preserve chronological order.
4. Keep each entry concise.

## Entry Format

```md
## Date

YYYY-MM-DD

## Task

Describe the development task.

## AI Tool

Gemini
Claude
Antigravity
Other

## Agent

Planner
Architect
Reviewer
Coder
Researcher
Other

## Purpose

Why AI was used.

## Outcome

What was produced.

## Files

List modified files.

## Notes

Additional relevant information.
```

## Rules

- Record only meaningful AI-assisted work.
- One entry per completed task.
- Keep descriptions objective.
- Do not modify previous records.
